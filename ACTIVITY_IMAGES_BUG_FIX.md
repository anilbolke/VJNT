# Activity Images Bug Fix

## Issue Found
```
Error: java.lang.NumberFormatException: For input string: "'   activity.activityId   '"
Location: OtherSchoolActivityImageServlet.doGet() line 20
```

The error shows that the `activityId` parameter is being passed as a literal string `'   activity.activityId   '` instead of the actual numeric ID.

## Root Cause
The JavaScript that builds the image URLs for school activities wasn't properly escaping URL parameters. When the HTML was generated by Java's `println()`, the quote handling created malformed JavaScript.

## The Fix

### Before (Broken)
```java
out.println("html += '<img src=\"/VJNT_Class_Managment/OtherSchoolActivityImageServlet?activityId=' + activity.activityId + '&photoType=photo1\" ...'");
```

### After (Fixed)
```java
out.println("html += '<img src=\"/VJNT_Class_Managment/OtherSchoolActivityImageServlet?activityId=' + encodeURIComponent(activity.activityId) + '&photoType=photo1\" ...'");
```

## What Changed
- Lines 494 & 497 in `PublicSchoolLookupServlet.java`
- Wrapped `activity.activityId` with `encodeURIComponent()` for proper URL encoding
- This ensures the activity ID is properly formatted as a URL parameter
