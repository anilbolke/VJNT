HOW IT WORKS:

1. User enters/shares URL with UDISE in path:
   http://localhost:8080/VJNT_Class_Managment/27150201202

2. Servlet extracts UDISE from URL path (not from search form)
   pathInfo = "/27150201202"
   udiseNo = "27150201202"

3. Fetches data from database:
   - School details (schools table)
   - School contacts (school_contacts table)
   - Palak Melava meetings (APPROVED only)
   - School activities (APPROVED only)

4. Renders complete HTML page dynamically (in servlet):
   - No search form
   - No input needed
   - Instant display

5. Shows:
   ✓ School name, UDISE, district
   ✓ Contact information
   ✓ Approved parent-teacher meetings
   ✓ Approved school activities

==============================================================================
                        IMPORTANT NOTES
==============================================================================

1. URL Format:
   - UDISE must be in URL path (not search form)
   - Example: /27150201202 (11-12 digit number)

2. Data Privacy:
   - Only APPROVED records display
   - Pending/rejected records hidden
   - No sensitive audit data shown

3. Security:
   - No login required
   - SQL injection prevention (PreparedStatements)
   - XSS prevention (HTML encoding)
   - Safe error messages

4. Browser vs API:
   - Browser visit → HTML page
   - API call with Accept: application/json → JSON response
