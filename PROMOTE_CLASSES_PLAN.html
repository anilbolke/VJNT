Complete Implementation Plan

🎓 Promote Classes + AUDIT + GRADUATED

Classes 1–8 promote normally (1→2 … 8→9). Class 9 students have completed the final class — they move permanently to graduated_students and exit the active system. All phase data and approvals are archived, never deleted.

🗄️ 4. SQL — Full 6-Step Promotion Sequence
🔐 All 6 steps run inside a single database transaction. If any step fails, everything rolls back — no partial state.

Step 1 — Create Promotion Log Entry

-- First, so we have @promo_id for all FK references below
INSERT INTO class_promotion_log
  (academic_year, promoted_by, promotion_date, remarks)
VALUES
  ('2025-26', 'admin_username', NOW(), 'Year-end promotion June 2026');

SET @promo_id = LAST_INSERT_ID();

Step 2 — Archive ALL Active Student Phase Data (Classes 1–8)

-- Full snapshot of every active student before anything changes
INSERT INTO student_phase_history (
  promotion_id, student_id, student_name, student_pen,
  udise_no, division, district,
  class_before, class_after,
  phase1_marathi, phase1_math, phase1_english, phase1_date,
  phase2_marathi, phase2_math, phase2_english, phase2_date,
  phase3_marathi, phase3_math, phase3_english, phase3_date,
  phase4_marathi, phase4_math, phase4_english, phase4_date,
  archived_at
)
SELECT
  @promo_id,
  student_id, student_name, student_pen,
  udise_no, division, district,
  class,
  CASE WHEN class = '9'
       THEN 'GRADUATED'
       ELSE CAST((CAST(class AS UNSIGNED) + 1) AS CHAR)
  END,
  phase1_marathi, phase1_math, phase1_english, phase1_date,
  phase2_marathi, phase2_math, phase2_english, phase2_date,
  phase3_marathi, phase3_math, phase3_english, phase3_date,
  phase4_marathi, phase4_math, phase4_english, phase4_date,
  NOW()
FROM students
WHERE is_active = 1;

Step 3 — Move Class 9 Students to graduated_students

-- Class 9 = FINAL CLASS. Copy full record to permanent graduate table.
INSERT INTO graduated_students (
  promotion_id, student_id, student_name, student_pen, gender,
  udise_no, division, district, section,
  graduated_from_class, academic_year,
  final_marathi_level, final_math_level, final_english_level,
  fln_completed,
  phase1_marathi, phase1_math, phase1_english,
  phase2_marathi, phase2_math, phase2_english,
  phase3_marathi, phase3_math, phase3_english,
  phase4_marathi, phase4_math, phase4_english,
  graduated_at
)
SELECT
  @promo_id, student_id, student_name, student_pen, gender,
  udise_no, division, district, section,
  '9', '2025-26',   -- graduated_from_class = 9 (final class)
  phase4_marathi, phase4_math, phase4_english,   -- final levels
  fln_completed,
  phase1_marathi, phase1_math, phase1_english,
  phase2_marathi, phase2_math, phase2_english,
  phase3_marathi, phase3_math, phase3_english,
  phase4_marathi, phase4_math, phase4_english,
  NOW()
FROM students
WHERE class = '9' AND is_active = 1;

-- Mark Class 9 students inactive — row kept, never deleted
UPDATE students
SET
  is_active    = 0,
  updated_by   = 'admin_username',
  updated_date = NOW()
WHERE class = '9' AND is_active = 1;

Step 4 — Archive Phase Approvals then Clear

INSERT INTO phase_approvals_history (
  promotion_id, udise_no, phase_number,
  approval_status, approved_by, approval_date, remarks, archived_at
)
SELECT
  @promo_id, udise_no, phase_number,
  approval_status, approved_by, approval_date, remarks, NOW()
FROM phase_approvals;

-- Safe to clear now — original data is in history
DELETE FROM phase_approvals;

Step 5 — Promote Classes 1–8 (UPDATE)

-- Classes 1-8 all increment by 1 (Class 8 becomes Class 9)
-- Class 9 already handled above (graduated), so BETWEEN 1 AND 8
UPDATE students
SET
  class          = CAST((CAST(class AS UNSIGNED) + 1) AS CHAR),

  -- Seed Phase 1 from last year's Phase 4 (carry-forward baseline)
  phase1_marathi = phase4_marathi,
  phase1_math    = phase4_math,
  phase1_english = phase4_english,
  phase1_date    = NULL,   -- not yet assessed in new year

  -- Wipe Phases 2, 3, 4
  phase2_marathi = NULL, phase2_math = NULL, phase2_english = NULL, phase2_date = NULL,
  phase3_marathi = NULL, phase3_math = NULL, phase3_english = NULL, phase3_date = NULL,
  phase4_marathi = NULL, phase4_math = NULL, phase4_english = NULL, phase4_date = NULL,

  updated_by     = 'admin_username',
  updated_date   = NOW()

WHERE is_active = 1
  AND CAST(class AS UNSIGNED) BETWEEN 1 AND 8;

Step 6 — Update Promotion Log Counts

UPDATE class_promotion_log
SET
  students_promoted  = (SELECT COUNT(*) FROM students
                        WHERE is_active = 1
                          AND CAST(class AS UNSIGNED) BETWEEN 2 AND 9),
  students_graduated = (SELECT COUNT(*) FROM graduated_students
                        WHERE promotion_id = @promo_id)
WHERE promotion_id = @promo_id;

🛠️ 6. Implementation Steps (In Order)

Step 1 — Run SQL: Create 4 New Tables

create_audit_tables.sql
  • Create class_promotion_log
  • Create student_phase_history (FK to promotion log)
  • Create graduated_students (FK to promotion log)
  • Create phase_approvals_history (FK to promotion log)
  • Run once on the database — no app restart needed

Step 2 — Add DAO Methods to StudentDAO.java

StudentDAO.java
  • List<Map> getPromotionPreview() — returns class-wise counts + Class 8 graduate count
  • Map promoteAllClasses(String username, String academicYear, String remarks) — runs all 6 SQL steps in a single connection with setAutoCommit(false), commit on success, rollback on any failure

Step 3 — Create PromoteClassesServlet.java

PromoteClassesServlet.java
  • Check session → must be DATA_ADMIN, else return 403
  • GET: return JSON from getPromotionPreview()
  • POST: accept academicYear + remarks params, call DAO, return JSON {success, promoted, graduated, promotionId}

Step 4 — Create promote-classes.jsp

promote-classes.jsp
  • On load: fetch preview → show table: Class 1→2: N students … Class 8→Graduated: N students
  • Academic Year input (auto-filled: "2025-26", editable)
  • Optional Remarks text area
  • Type-to-confirm: must type "PROMOTE" to enable button
  • On confirm: POST → spinner → success card showing Promotion ID, students promoted, students graduated

Step 5 — Create promotion-audit.jsp

promotion-audit.jsp
  • Lists all past promotions from class_promotion_log (newest first)
  • Columns: ID, Academic Year, Date, Admin, Promoted, Graduated
  • "View Details" expands to show student_phase_history for that promotion
  • Filter by Division / District for drill-down

Step 6 — Create graduated-students.jsp

graduated-students.jsp
  • Lists all rows from graduated_students (newest year first)
  • Filter by: Academic Year / Division / District / UDISE
  • Columns: Name, PEN, School, Year, Final Marathi/Math/English level, FLN Completed
  • Shows summary count at top: "Total Graduated: 1,240 across 3 years"

Step 7 — Update data-admin-dashboard.jsp

data-admin-dashboard.jsp
  • Add "Promote Classes" card — orange gradient
  • Add "Promotion Audit" card — green gradient
  • Add "Graduated Students" card — gold gradient

Step 8 — Register Servlet + Build + Test

web.xml
  • Register PromoteClassesServlet at /promote-classes
  • Build WAR and deploy to Tomcat
  • Test: verify Class 7→8 promoted, Class 8→graduated, phase history rows created, approvals archived
