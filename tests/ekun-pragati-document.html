📁 Project: VJNT Class Management 📅 Date: February 2026

Overview

The ⭐ एकूण प्रगती (Overall Progress) field on the Student Report Card shows a single consolidated level that represents the student's average performance across three subjects: मराठी, गणित, and इंग्रजी.

Displayed in print-student-report-card.jsp (line ~642): ⭐ एकूण प्रगती: ${data.assessmentLevels.overall}

Data Source

Three integer columns from the students table:

ColumnSubjectRange0 means
marathi_akshara_levelमराठी0 – 6Not Assessed
math_akshara_levelगणित0 – 8Not Assessed
english_akshara_levelइंग्रजी0 – 6Not Assessed

3. Calculation Steps

1
Read DB
Fetch 3 level integers from students table
2
Filter
Skip subjects where level = 0 (not assessed)
3
Sum
Add levels of assessed subjects only
4
Average
sum ÷ assessedCount
5
Round
Math.round() — 0.5 rounds UP
6
Map
Round value → Level Name string
avgLevel = Math.round( (m + ma + e) / assessedCount )

Edge Cases & Known Issues

⚠️ मराठी Level 6 Issue The math_akshara_level goes up to 8 and marathi_akshara_level goes up to 6, but the overall levelNames array only has indices 1–5. If the average rounds to 6, 7, or 8, the code falls back to raw "Level 6" text with no Marathi label.

Fix recommendation: Cap each subject level at 5 before adding to sum: levelSum += Math.min(marathiLevel, 5);
📌 Rounding Rule Java's Math.round() uses "half-up" rounding — 0.5 always rounds UP. Example: avg 2.5 → rounds to 3 → Level 3 – प्रवीण
📌 Single Subject Assessed If only one subject is assessed, that subject's level IS the overall level. Example: मराठी=4, गणित=0, इंग्रजी=0 → avg = 4/1 = 4.0 → Level 4 – प्रगत
